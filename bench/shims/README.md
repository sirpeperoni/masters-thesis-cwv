# shims

Обёртки для команд пакетных менеджеров, которые вызывают сами скрипты сборки проектов
(например, `"build": "pnpm build:embed && vite build"`). У нас pnpm/yarn доступны только
через corepack, поэтому конфиг репозитория добавляет эту папку в начало PATH.

`pnpm.cmd` отключает `confirm-modules-purge` (при смене мажорной версии pnpm он спрашивает
подтверждение пересоздать node_modules, а без терминала прерывается — так упала проба vuejs/docs
на переходе pnpm 9 → 10) и `engine-strict`: новые коммиты требуют Node ≥ 24, а стенд работает на
Node 22 — одинаковом для всех коммитов (иначе версия Node стала бы ещё одним отличием
между базой и коммитом).
