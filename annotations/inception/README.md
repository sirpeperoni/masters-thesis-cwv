# Разметка текста в INCEpTION (онлайн-демо)

Материалы для задания «Создайте свой проект в INCEpTION, предварительно подготовив текстовый файл».
Тексты — описания коммитов и pull request'ов фронтенд-проектов из корпуса лабораторной № 3
(`annotations/text-desc/`), схема сущностей — `docs/annotation-schema.md`, раздел «Текст: описание изменения».

| Файл | Что это |
|---|---|
| `commit-descriptions.txt` | **текстовый файл для проекта**: 5 описаний подряд (≈ 4,3 тыс. символов) |
| `texts/P01.txt … P40.txt` | те же 5 описаний по одному в файле — если удобнее отдельными документами |
| `tagset-cwv-entities.json` | набор тегов для слоя Named entity (17 тегов) — импорт в INCEpTION |
| `preannotated/*.tsv` | те же 5 документов с готовой автоматической разметкой (части речи + сущности), формат WebAnno TSV 3.3 |

Документы: P01 — обновление зависимостей mermaid-live-editor; P02 — интерфейс ссылок excalidraw;
P09 — исправление экспорта mermaid (ссылки на issue); P19 — версии Vue в документации; P40 — фреймы excalidraw.

## Шаги

Названия кнопок — по текущей версии INCEpTION; в демо они могут немного отличаться.

1. **Демо.** На https://inception-project.github.io нажать *Try INCEpTION online* → *Proceed to the demo*
   (открывается временная учётная запись).
2. **Чужой проект.** Открыть пример из задания
   (`https://morbo.ukp.informatik.tu-darmstadt.de/p/demo-8255/annotate?20#!d=55315&f=1`): посмотреть слои,
   как выделяется сущность и выбирается её тип, как устроены связи (relations). Сделать снимок экрана для отчёта.
3. **Свой проект.** *Projects* → *Create new project*, название, например, «CWV commit descriptions».
4. **Документ.** *Settings* → *Documents* → выбрать `commit-descriptions.txt`, формат **Plain text** → *Import*.
5. **Набор тегов.** *Settings* → *Tagsets* → *Import* → `tagset-cwv-entities.json` (формат JSON).
   Если импорт не принимает файл — *Create*, имя «CWV commit entities», и добавить теги вручную по таблице ниже.
6. **Слой.** *Settings* → *Layers* → **Named entity** → признак (feature) *value* → *Tagset*: «CWV commit entities».
   Галочка *Annotators may add new tags* — снять (словарь закрытый, как в схеме).
7. **Разметка.** *Annotation* → открыть документ → выделить мышью слово или фразу → в правой панели выбрать
   слой *Named entity* и тег. Разметить хотя бы 15–20 сущностей разных типов: пакеты (`vite`, `eslint`),
   версии (`8.0.16`), элементы интерфейса (`toolbar`), действия (`bump`, `fix`), ссылки (`#1797`).
   Документ закрыть кнопкой *Finish document* (замок).
8. **Готовая разметка (по желанию).** Загрузить `preannotated/P02.tsv` как документ в формате
   **WebAnno TSV v3.x** — откроется уже размеченным (части речи и сущности, найденные автоматически).
   Можно сравнить с ручной разметкой того же текста (`texts/P02.txt`).
9. **Экспорт.** На странице разметки *Export* (или *Settings* → *Export* для всего проекта) — формат
   **WebAnno TSV v3.3** или **UIMA CAS XMI**. Файл приложить к отчёту.

Демо-сервер временный: проекты на нём со временем удаляются — экспорт и снимки экрана сделать сразу.

## Набор тегов (слой Named entity)

| Тег | Что размечается | Пример |
|---|---|---|
| FRAMEWORK | фреймворк | Svelte, React, Vue |
| BUILD_TOOL | сборщик, менеджер пакетов | Vite, pnpm, ESLint |
| STYLE_LIB | библиотека стилей | Tailwind |
| PACKAGE | прочий npm-пакет | monaco-editor, mode-watcher |
| VERSION | номер версии | 8.0.16, ^1.0.1, 3.x |
| UI_COMPONENT | элемент интерфейса | editor, toolbar, popover |
| DOMAIN_OBJECT | объект предметной области | frame, diagram, link |
| PERF | упоминание производительности | bundle size, lazy load |
| ADD / REMOVE / UPDATE / FIX / REFACTOR | действие изменения | add · remove · bump · fix · migrate |
| CODE | идентификатор кода, путь | `mode.current`, src/lib/util/mermaid.ts |
| ISSUE / COMMIT | ссылка на issue/PR или коммит | #1797 · 3e9f40b |
| PERSON | упоминание человека | @aloisklink |

## Что положить в отчёт

1. Снимок демо-проекта из задания (шаг 2).
2. Снимки настроек своего проекта: документ, набор тегов, слой (шаги 4–6).
3. Снимок размеченного документа (шаг 7).
4. Экспортированный файл (шаг 9) и короткий вывод: сколько сущностей каких типов размечено, что было
   неоднозначно (например, `link` — элемент интерфейса или объект предметной области).
